# piper-draft-spec

A Piper Morgan skill that turns a rough idea into a complete feature spec.

## What it does

Takes a rough idea, brief, or conversation and produces a properly-formed feature spec / PRD — with problem statement, goals, non-goals, user stories, requirements, open questions, and success criteria.

## Trigger phrases

- "write a spec for"
- "draft a PRD"
- "spec this out"
- "write this up properly"
- "I want to build X"

## Requirements

Works best with project context (current sprint, team patterns). Also works standalone.
