# piper-draft-issue

A Piper Morgan skill that drafts a properly-formed GitHub issue from a rough idea.

## What it does

Turns a problem statement, bug report, or feature idea into a structured issue with SLUG, Problem Statement, Goal, Requirements, Acceptance Criteria, and correct metadata (priority, labels, milestone).

## Trigger phrases

- "file an issue"
- "create a ticket"
- "draft an issue"
- "track this"
- "we should file a bug for"

## Requirements

Works with any issue tracker. Detects GitHub repos automatically; adapts for Linear, Jira, or manual filing.
