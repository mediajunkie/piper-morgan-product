Set up Slack for Piper Morgan

This creates the Slack app that lets Piper reply to your DMs and @mentions, and gives you the /link and /standup commands. You'll do everything in two tabs: Slack's app console and Piper's settings page.

  1. Create the app in your workspace
  2. Turn on Socket Mode and generate the app token
  3. Give the bot its permissions
  4. Subscribe to messages and mentions
  5. Add the slash commands
  6. Install and copy the bot token
  7. Paste both tokens into Piper
  8. Link your account and try it

1Create the app in your workspace

  1. Open api.slack.com/apps. Check the workspace switcher in the top-right corner — apps belong to one workspace, and the list only shows apps for the workspace you're signed into. (If an app you remember seems to have vanished, it's almost certainly listed under a different workspace, such as an older one.)
  2. Click Create New App → From scratch.
  3. App name: Piper Morgan. Pick the workspace you actually chat in. Click Create App.
Checkpoint: you're on the app's Basic Information page, with a left sidebar of settings.

2Turn on Socket Mode and generate the app token

  1. In the left sidebar: Settings → Socket Mode → toggle Enable Socket Mode on.
  2. Slack immediately asks you to create an app-level token. Name it piper-socket, and confirm it has the scope connections:write. Click Generate.
  3. Copy the token — it starts with xapp-. Park it somewhere safe for phase 7 (you can always regenerate it later under Basic Information → App-Level Tokens).
Checkpoint: Socket Mode shows as enabled, and you have an xapp-… token copied.
Why Socket Mode: it lets Piper connect out to Slack, so there's no public webhook URL to configure anywhere — every screen that asks for a "Request URL" can be left alone.

3Give the bot its permissions

  1. Left sidebar: Features → OAuth & Permissions, scroll to Scopes → Bot Token Scopes.
  2. Add each scope below with Add an OAuth Scope:
ScopeWhat it's for
chat:writeSending replies
im:historyReading the DMs you send it
im:readSeeing its DM conversations
app_mentions:readHearing @Piper Morgan in channels
commandsThe /link and /standup commands
users:readKnowing who's talking to it
team:readKnowing which workspace it's in
channels:history, channels:readOptional — richer channel awareness; skip if you only plan to DM
Checkpoint: the Bot Token Scopes list shows at least the first seven scopes.

4Subscribe to messages and mentions

  1. Left sidebar: Features → Event Subscriptions → toggle Enable Events on. (No Request URL needed — Socket Mode carries the events.)
  2. Expand Subscribe to bot events and add both:
message.im direct messages to the bot app_mention @Piper Morgan in a channel
  1. Click Save Changes (bottom of the page).
Checkpoint: both events are listed and the page shows saved.

5Add the slash commands

  1. Left sidebar: Features → Slash Commands → Create New Command. Leave any Request URL field alone (Socket Mode again). Create each of these:
CommandShort descriptionUsage hint
/linkLink this Slack account to Piper Morgan[code]
/standupGet your standup from Piper
/piperPiper commands and help[help]
Checkpoint: three commands listed under Slash Commands.

6Install and copy the bot token

  1. Left sidebar: Settings → Install App → Install to Workspace → Allow.
  2. Copy the Bot User OAuth Token — it starts with xoxb-.
Checkpoint: you now hold two tokens — xapp-… from phase 2 and xoxb-… from here.
If you change scopes, events, or commands later, Slack banners "reinstall your app" at the top of the console. Click it — changes don't take effect until you do.

7Paste both tokens into Piper

  1. In Piper: Settings → Integrations → Slack.
  2. In Enable Slack replies, paste the xapp-… token and save.
  3. In the Slack connection section, provide the xoxb-… bot token where asked.
  4. The status indicator should flip to listening within a few seconds — no restart needed.
Checkpoint: the Slack settings page shows Piper is listening.

8Link your account and try it

  1. Sanity check first: in Slack, open a DM with Piper Morgan and say hello. You should see a brief …thinking… and then a real reply.
  2. Back on Piper's Slack settings page, find Link your Slack account and click Mint link code.
  3. In Slack, send /link YOURCODE (the code works once and expires after about ten minutes).
  4. Try /standup — you should get your own standup, because Slack now knows which Piper account you are.
Checkpoint: DM replies work, /link confirmed, /standup answers as you. Done — this was all one-time; from here Slack just works.
