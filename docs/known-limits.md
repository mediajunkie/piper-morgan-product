# Known limits

**Status: DRAFT 2026-11-13.** These are limits of what Piper offers today, written the way Piper would say them. CXO has not passed the wording and nobody has checked each limit on a served build, so this page is not yet used as Piper's own source. The tester page [ALPHA_KNOWN_ISSUES.md](./ALPHA_KNOWN_ISSUES.md) keeps the tester-only items and the release history.

## Chat and data

- **Counting issues.** When you ask how many issues you have open, my number can be too high. I may be counting issues assigned to you in every repository, archived ones included, and "most recent" may not be in date order.
- **Milestones.** I can't reliably list the issues in a milestone yet. If you ask, I may show you the wrong ones. Check the milestone in GitHub before you rely on my list.
- **Deleting several todos at once.** If you ask me to delete two todos in one message, I may delete only the first and not tell you about the second. Ask me one at a time.
- **Overdue todos.** When I show your todos, an open overdue one can appear crossed out, which makes it look finished. It isn't.
- **Sharing.** Sharing a todo, list or project from the screen fails for now, and you see an error. I can't do it yet.
- **Several requests in one message.** If you put more than one request in a message, I can lose an offer or a question from one part, or show it as plain text. Send them as separate messages.
- **A failed action that looks like a success.** For one kind of action, a learned pattern, I can say it worked when it didn't. If it matters, check the result yourself.
- **Preferences on a repeated question.** If you ask something I answered recently, I may reuse that answer and skip a preference you've set since.

## Interface

- **iPad in portrait.** On an iPad in Safari held upright, a new chat can open as an empty gray panel with the message box pushed off the screen.
- **Deleting or archiving a chat.** I can't offer you a button to delete or archive a whole conversation right now.
- **Private session.** The "Start private session" switch in History only changes how the page looks. It doesn't change what I keep, so don't rely on it for privacy.

## Using me inside another app

- **The Claude and MCP connection.** Using me inside Claude or another MCP client is newer and rougher than the web app. Expect more rough edges there.
