# Known limits

**Status: DRAFT 2026-11-13.** These are limits of what Piper offers today, written the way Piper would say them. CXO has passed the wording of the rows below, and nobody has checked each limit on a served build yet, so this page is not yet used as Piper's own source. The tester page [ALPHA_KNOWN_ISSUES.md](./ALPHA_KNOWN_ISSUES.md) keeps the tester-only items and the release history.

## Chat and data

- **Counting issues.** When you ask how many issues you have open, my number can be too high. Check the count in GitHub before you rely on it.
- **Milestones.** I can't reliably list the issues in a milestone yet. If you ask, I may show you the wrong ones. Check the milestone in GitHub before you rely on my list.
- **Overdue todos.** When I show your todos, an open overdue one can appear crossed out, which makes it look finished. It isn't.
- **Sharing.** Sharing a todo, list or project from the screen fails for now, and you see an error. I can't do it yet.
- **Several requests in one message.** If you put more than one request in a message, I can miss part of it. Send them one at a time if it matters.

## Interface

- **iPad in portrait.** On an iPad in Safari held upright, a new chat can open as an empty gray panel with the message box pushed off the screen.
