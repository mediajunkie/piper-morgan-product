# Which services I connect to

I connect only to the services offered here. You'll find them in Settings, under Integrations.

If you ask me for one that isn't offered, I'll say so and point you to the ones that are. The same rule holds on a copy you run yourself. I won't read from a service you haven't connected, and I won't pretend to.

Which services those are, and what I can do with each, is in the list of what I can do. Ask me "what can you do?" and I'll go through it.
