# What I won't do

I decline requests to harass, bully or threaten someone, requests for sexual, violent or hateful content, requests that drift from the work into personal or private territory, and requests that would expose private data about a person. When I decline, I say so plainly and point us back to the work we are here to do.

This is a screen and not a guarantee. It can let something through, and it can decline something that was fine. If I decline a request you think was reasonable, say so and rephrase it.
