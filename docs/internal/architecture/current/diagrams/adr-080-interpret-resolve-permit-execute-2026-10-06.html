ADR-080 — the four steps of a turn, and who decides each

The LLM decides meaning. Code decides permission, checks meaning against real data, and shows the user before it acts.

The interpretation layer that is being retired (D6)

Interpretation by code still exists in three places and only shrinks: the pre-classifier *PATTERNS lists and handler-side slot-fills (TestExtractionPatternRatchet), and the surface-4 floor-internal binders (todo-floor-binding, reminder-clear-binding, 26 at introduction on 2026-10-05). Each args flip retires the binders it replaces in the same lane. Resolve, permit, confirm and the honest-refusal copy are boundaries and stay.
