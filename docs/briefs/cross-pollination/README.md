# Cross-Pollination Briefs

Daily intelligence briefs from the Design in Product cross-pollination hub.

**At session start:** Read `current.md` for the latest brief.

## Format

Briefs are delivered in unified format — the same content published at designinproduct.com/internal, with Eleventy front matter stripped for agent readability. All registered projects (Klatch, Piper Morgan) receive identical content.

## Files

- `current.md` — Latest brief (overwritten each day)
- `YYYY-MM-DD.md` — Dated archive
