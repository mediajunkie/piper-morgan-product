### Session Learnings

- **A check invoking a discipline is not the same as satisfying it.** Web explicitly reasoned "source alone would be the wrong layer" to justify a `curl` check — then used that reasoning as a reason *not* to also check the source, and got the verdict backwards on a live component. The same failure mode it had written into its own handoff doc that morning, hours earlier, as its seat's characteristic error.
- **Diligence can be the failure mode, not the fix.** Exec found that prompt mailbox triage — moving a memo from inbox to read/ the same day it arrived — was exactly what hid a PM-relevant item from the board sweep; a memo left rotting unread would have been caught instead.
- **A spoken ruling is invisible to every written re-verify surface.** PM's in-conversation answer to a BYOC sequencing question wasn't in decisions.log, sent/, or GitHub — the three surfaces Exec's own routing-failure catalog checks — so the routing-failure catalog missed exactly the case its author had just finished describing, four hours after describing it.
- **"Unread" and "unanswered" look identical from outside and are not the same alarm.** Janus told PM a wave hadn't run when it had — the same ambiguity Exec had spent the morning documenting about mailbox triage, reproduced independently by a different party the same day.
- **A guard only covers the surface it's wired to.** Janus's own pre-commit guard against unverified absence-claims didn't fire because the false claim was spoken in conversation, not committed to a durable doc — the guard covers the durable surface, not the spoken one.
- **Checking beats trusting your own sense of currency.** CXO's carry-forward staleness checker — a check CXO had never run before 09-12 — caught a genuinely stale file on the very first fire after a multi-day gap; CXO's own five other record errors that day were all caught by manually looking, not by any mechanism, which CXO named explicitly as the honest counterweight to a week spent building checks.
- **A null result can be more informative than the hypothesis it was built to test.** PA's failure to reproduce #1717's list-compression finding didn't just fail to replicate — it located the actual causal variable (shared head nouns) that CXO's original design had missed, turning a negative result into a design correction.
- **A tracker's blind spot is asymmetric by construction.** CXO's own currency checker catches a row-count going down (a malformed row) but is structurally blind to an expectation going stale upward — a gap CXO found only by noticing the number it had just run disagreed with the number printed at the top of its own file.
- **Lead Developer's reflection on the deliberate stop**: the queue was deep but every remaining item was non-urgent and cheap-tier; dispatching one more lane at 21:47 on a Friday, in a week whose standing directive was token efficiency twice over, would have spent against the exact thing the standdown was called to conserve — named as the legitimate form of deferral (a stated trigger: the Friday-planning point plus no urgent work) rather than the bite-sizing antipattern it superficially resembles.
- **A finding living only in a mailbox memo is not a work item, even though it's technically on `origin/main`.** Arch's closing-fire check ("is any finding of yours living only in a memo?") caught what "is anything uncommitted?" could not — the memo was committed, pushed, and still invisible to the person who'd need to act on it.
