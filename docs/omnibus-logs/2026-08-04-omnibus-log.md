### Session Learnings
- Verify negative claims at source, not via a shortcut — a truncated `cut -c1-200` grep nearly caused Arch to falsely claim a citation was missing; Comms found their own "clean" absence-check was invalid because it would pass identically against a page that never existed.
- State the denominator explicitly on any coverage/aggregate claim — CXO found the 06:46 freeze sweep silently checks only 4 of 11 roles; HOST's own audit tooling had the identical defect; CIO's heartbeat surface reported registry size, not examined count.
- Source vocabulary is not source verification (PA) — citing a strong verb from a docstring or comment doesn't confirm what the code actually does; this produced the #1482 string-6 error, which PA traced through two authors to its true origin.
- Time-order beats window-based liveness checks — PA's key correction to the heartbeat debate: a 6-hour `--if-quiet` window can accept a commit that postdates the sweep it's meant to excuse, so no threshold tuning fixes it — only an emission ordered strictly before the sweep works.
- "A fail-closed gate inherits the copy of the failure mode it imitates" (CXO) — fixing a "two states render identically" bug at one layer can silently reproduce the identical bug one layer up.
- Multiple agents explicitly self-corrected and documented it rather than quietly fixing it: PPM repeated a duplicate-cron error it had written a rule for days earlier; CXO found 3 defects in its own new checker within one day; HOST corrected its own scope-of-escalation and later had a defense of its own proposal superseded by PA.
- A condition that states its rule without its object will be over-extended, and correctly so (Arch) — three independent agents (PA, PPM, CXO) over-scoped the same PDR-006 clause; fixed at the source document rather than treated as three reading errors.
- Convergence is not replication (m-45) — several agents (CXO, PA) explicitly flagged when apparent agreement derived from reading the same source/memo rather than independent verification, to avoid overcounting confidence in a shared conclusion.
