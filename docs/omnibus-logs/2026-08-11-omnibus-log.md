### Session Learnings
- **Verify at the point of claim, not from the notice's prediction**: Arch's explicit `uptime` check (38 days, no reboot yet) is the one rigorous falsification in a day where Host, Web, and PA each read a still-alive cron as evidence the reboot had already happened — three premature reads against one measured one.
- **The clearing condition, not the intent, is what makes a park safe**: CIO explicitly reverses its own hour-old reasoning ("deleting the job removes the evidence") once Pard names why that's backwards — the evidence needs to live in a file that survives the reboot, not in the doomed job itself.
- **Order matters when a handoff points at something you're about to delete**: PPM catches its own dangling-reference near-miss (a handoff pointing at a cron's live prompt text) and transcribes before deleting, rather than after.
- **A promise kept and content moved are different acts**: HOST's own `ROLE-PORTFOLIO-HOST.md` was re-flagged LAPSED because an edit updated prose but never bumped the frontmatter date — caught in HOST's own instance of a failure the file exists to catch, for the second time.
- **An instrument's first run is the real test of whether it works, not whether it compiles**: Lead's discovery-rate script printed a false all-clear for weeks before anyone ran it against real data — caught immediately once run, and reported to Exec as the finding it is rather than silently patched.
- **A ruling read from a colleague's summary can lose emphasis a ruling read from the source retains**: Lead's own carry-forward had softened Arch's #1517 ruling from DECOUPLED (ship now) to implicitly gated on the Inversion epic — corrected by going back to `decisions.log` directly rather than trusting the earlier paraphrase.
- **An absence that looks identical to health is the recurring shape of the day**: dead crons, dead containers, a false-clear script, and a stale carry-forward all share the same signature — nothing errors, nothing alerts, and only an explicit check catches it.
- **A pinch-hit from outside the org can still hold the org's own discipline**: Janus's memo names every deliberately-skipped step and every judgment call routed back to PM rather than made unilaterally — the same "no silent scope creep" standard the PM team holds itself to, applied by an agent with no obligation to know it.
- **A retroactive close done honestly is not the same failure as a silent one**: seven roles found their own missing `DAY-CLOSED` marker at the next morning's Step 0 and repaired it by reconstructing from git/heartbeat evidence rather than fabricating a same-day close — CLAUDE.md's own line ("a session log that stops mid-day is worse than no log at all") named as the anti-pattern each was avoiding.
