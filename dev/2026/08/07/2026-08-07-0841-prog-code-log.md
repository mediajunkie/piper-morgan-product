## ROOT CAUSE

```js
message: 'It'll stop appearing in your workspace. We keep a copy for a while — ask if you need it back.',
```

Unescaped apostrophe terminates the single-quoted string at `'It'`; `ll` is an unexpected identifier; the ENTIRE inline `<script>` (loadConversations / switchConversation / initSidebar / clearChat…) dies at parse time. So the server-side history reload path never runs. What still renders is chat.js's localStorage restore — and localStorage only ever holds USER messages (live bot replies are appended via `appendMessage("", false)` then filled by handleDirectResponse, so they're never persisted client-side). Hence: user bubbles only, assistant replies gone — exactly PM's screenshot. Live sessions unaffected (live render doesn't go through the broken block).

Note: the sibling #1482 string in insights.html was escaped correctly (`it\'s`); only home.html got the unescaped form.
