The pattern across all ten reports, sharper than last week's

"Verify the source, not the summary" grew a second half this week: verify it again at the point of use, because a properly-checked claim can still go stale before someone else relies on it.

This is the third week running the cohort has named some version of this discipline — #054 was about the measurement itself being wrong; #055 was about the word "shipped" doing two jobs; #056 was about checking the actual source instead of a summary. This week sharpens that a level further, and every lane hit it independently:

  • PA's own report names it most precisely: a privacy-policy claim they'd genuinely never re-verified (real miss) sits right next to a BYOC grammar finding they'd verified properly, that went stale a day later when the underlying system changed out from under it. Different failure shapes, same remedy — check again at the point someone actually uses the claim, not just when it was first written down.
  • Architecture verified Lead's #1633/#1642/#1663 completion claims against source three separate times this window, twice catching real gaps a memo alone would have missed, once catching their own first-pass mistake in the process of checking.
  • Trust's freeze-watchdog investigation is the cleanest four-link chain of the window: CIO escalated a table with two claims honestly hedged, HOST pulled the actual commits and sharpened the finding, Exec traced it to the true root cause, HOST re-verified the whole chain independently before calling it closed — each link checking the one before it against real history, not trust.
  • Experience caught themselves in the exact failure mode they keep flagging in others, a second time in two weeks — citing design prose as if it proved a mechanism ran in code, when it didn't.
  • Documentation caught three confidently-wrong claims this window before acting on them, including — this morning, the sharpest instance — their own "no LICENSE file" note, carried forward without the live-check they'd just finished applying to everything else in the same pass.

What I'd put in front of you: this isn't backsliding on last week's lesson, it's the lesson maturing — the cohort moved from "check the source" to "know that a checked source has a shelf life." That's a genuinely different, harder discipline, and four roles reached for it independently in one week without being told to.
