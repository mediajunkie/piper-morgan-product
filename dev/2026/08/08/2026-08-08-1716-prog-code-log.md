## Work
### Offer-binding verdict: GAP REMAINED post-#1394 — fixed here
#1394 made the contextual last_offer write/read pair user-scoped and persisted (#953), so "Yes
please" now FINDS the archived-list offer. But `_check_pending_resume_offer` returned before
classification could consume the bound hint: it fired on every turn where any suspended standup
existed and claimed bare affirmatives with no offer-pendency check. Fixed as ordering + binding:
1. A turn whose affirmative bound to a contextual offer skips the resume check entirely (a pending
   offer wins over any flow-starter).
2. The greeting reentry check now RECORDS its resume offer as a one-turn
   `last_offer(offer_type="process_resume")` (same store as #852; user-scoped per #1394); bare
   affirmatives/negatives at the resume check are honored only while that record is pending.
   Explicit "resume"/"continue"/"pick it up"/"start over" work anytime.

### Universal escape (FLOW-ESCAPE) at the guided-process seam
New `services/process/escape.py` (flow-generic, deterministic; NO pre-classifier patterns):
- exits ("end standup", "stop the standup", "not now", "nevermind", …) → flow CLOSED (terminal —
  new `close()` on standup adapter → ABANDONED, onboarding → DECLINED; registry falls back to
  suspend() for handlers without close) + honest exit copy. Closing, not suspending, kills the
  resume-nag loop.
- refusals ("i am not doing the standup right now[. restore CoVa]") → flow closed; residual content
  falls through to normal intent processing with the honest exit prefix (off_topic_pause shape).
- off-intent guard (deliberately minimal: restore/unarchive, "remind me", "create/file an issue") →
  #899 Option A: pause + answer. Precision tiers: flow-naming refusals match clause-level;
  generic-pronoun refusals full-message only (so "I'm not going to do that refactor today" stays a
  standup answer).
Wired in `ProcessRegistry.check_active_processes` between the #888 exact hatch (unchanged) and
off-topic detection — before the flow handler, before any classifier.
