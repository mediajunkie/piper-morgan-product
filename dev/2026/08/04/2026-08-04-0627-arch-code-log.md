### ★ The tool found a false positive in itself

First run flagged **15**. One was **`test_every_derived_surface_has_a_ledger_row`** — #1433, landed on my own ratification — and reading the output showed **my checker was wrong**:


**A bidirectional pair is jointly non-vacuous.** Lead's test is sound by construction and I was crying wolf about it. Pair detection added; 15 → 14.
