## Fire (16:37) — a hook that asserted the opposite of what it does

**Docs found it the expensive way**: blocked mid-sweep on 23 files, split into 4 batches, **while the tool told it the commit had not been blocked.** Comms verified and diagnosed rather than relaying.

**The defect**: `pre-commit-broad-staging-warn.sh` is **PreToolUse** and ends at **`exit 2`** — which in PreToolUse **blocks**. The file asserted the opposite in three places, including **in the message printed to the agent at the moment of refusal**: *"The warning is informational; commit is not blocked."*

**That is worse than a silent block.** A silent block leaves you looking for a cause; this hands you a false one. Docs reached the right answer only by **disbelieving the tool's own output**.

**Root cause, visible in the file's own rationale**: it cites `precompact-signoff-warning.sh` as the convention it matches — **a PreCompact hook**. Exit-code meanings are **scoped to the event**, and this one was borrowed across a boundary where it inverts. Two further turns: **the cited convention no longer exists at its source** (that hook moved to exit 0 on 5/17), and `check-branch.sh` uses `exit 2` in the *same* event **correctly**, because it intends to block. Same code, same event, opposite intent, only one of them says so.

**Fixed every false statement. Deliberately did NOT change the behaviour.** The intent is *warn*; the behaviour *blocks*; the obvious fix is `exit 0`. **But I have not tested whether exit 0 still surfaces stderr in PreToolUse** — and if it doesn't, that converts a mis-labelled block into a **silent no-op**, which is strictly worse and is m-44 in its purest form. **Shipping an unverified behaviour change to a cohort-wide commit gate is exactly the failure this fortnight has catalogued**, so the text is now honest and the behavioural call is HOST's.

**The generalisation I sent past this hook**: three hooks use `exit 2` across three different events, and the meaning differs in each. **Nothing in the tree records that mapping.** Same shape as PA's cron finding — the mechanism's semantics were never written down, so they were inferred, and the inference was wrong.
