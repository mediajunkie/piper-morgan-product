## Headline
The test corpus is large and mostly real (about 12.8k tests, 11,471 unit passes). The enforcement layer around it is not working: the **`Tests` workflow on main has had zero successful runs since 2026-09-20**, and `Fly deploy` pushes to staging on every main push regardless. Two other gates (mypy ratchet, schema-validation) are also red. Most of the 24 unit failures are environment-caused, but 16 are genuine stale tests left by the #1595 pattern deletions.

## Appendix
- test.yml `Full Test Suite` is the only job that runs the broad suite and is gated by a 47-entry known-failing backlog with shrink-lock in both directions (a fixed test must also be removed from the list). A good design; it needs a green smoke job to execute at all.
- Docker Build workflow (100/100 green) validates the image builds and imports; it does not run tests and is partly redundant with Fly's remote build.
- Run-time: serial unit suite 6m06s; with coverage 9m32s; non-unit 4m10s; CI Tests run ~4 min each, so every push to main costs about 4 min and then cancels the previous run when pushes are frequent (concurrency cancel-in-progress), which is why a third of runs show "cancelled".
