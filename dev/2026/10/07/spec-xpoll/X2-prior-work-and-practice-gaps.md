## 3. What the hub lacks for browsing / querying (confirmed against templates)

Static read of `HUB/src/internal/*.njk`, `.eleventy.js`, layouts, `package.json`:

1. **No search.** No search library (`package.json` lists only `@11ty/eleventy ^3.1.5`; grep for pagefind/lunr/fuse → none). The only `<script>` in `base.njk` (L51) is a `shareQuote()` helper. `briefs.njk` has no JS at all.
2. **No filtering of any kind.** `briefs.njk` (34 lines) is a single `{% for brief in collections.briefs %}` newest-first list of card summaries (L17–32); `archive/month.njk` paginates by month only (`.eleventy.js:18–42`). No filter by status, source project, topic, or date range beyond month.
3. **No tags/topics.** Front matter on all 234 files has only `layout,title,ogTitle,ogDescription,date,status,sources_checked,window` (+ `secondary_provenance` ×31, `revision` ×1) — script. No `tags`, `topics`, `category`, `insight_ids`. `daily-sweep.md` Step 5 mentions "insight tags" on hub cards (L137–143) but `index.njk` has none (grep "tag" → 0; the cards are now collection-driven).
4. **No insight-level objects.** An insight is an `### N.` heading in the body; Eleventy's default markdown does not add anchors *(inferred — no anchor plugin in `package.json`; page not built)*, so an individual insight has no stable URL, ID or data record. The only per-brief summary text surfaced is `ogDescription` (one paragraph for the whole day) — `briefs.njk:26`, `archive/month.njk:72`, `index.njk:37,51,63`.
5. **Nominal brief rendering hides content**: `briefs.njk:23–24` replaces a nominal brief's summary with a fixed sentence, "Sweep ran. No cross-relevant activity…" — even for 02-06 and 02-13, which now contain Background Changes (demoted insights).
6. **The `[0-9]-brief-rev2.md` file is outside the `briefs` collection** (`.eleventy.js:11,19` glob `*-brief.md`) — so 2026-04-11's substantive brief is unlisted in the archive *(inferred, unbuilt)*.
7. **No index, cross-reference, or "related" links** between briefs. `brief.njk` (the layout) renders only a back-link, a status badge, and `{{ content }}` — no previous/next, no related, no source links.
8. **No machine-readable feed.** No JSON/RSS/Atom/`/internal/briefs.json` output (grep of `src/internal/*.njk` and `.eleventy.js`). The Backlog §3b "agents as subscribers via MCP/RSS" is "LONG-TERM, no immediate trigger" (`backlog.md:137–139`).
