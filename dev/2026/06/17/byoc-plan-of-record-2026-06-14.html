Demo Concept (Loom skeleton)

Goal: record Piper running live, publish to pipermorgan.ai to gauge interest. No cohort needed — just PM + Claude Desktop + the plugin.

Surface 1 — Claude Desktop (primary)

Show the full flow: install plugin, run meet-piper (abbreviated), ask-piper a real PM question, get a grounded response. Narrate what's happening and why it's different from generic AI.

Surface 2 — Claude Code (secondary, optional)

Show that the same plugin works in Code — same Piper, same context. Demonstrates the multi-surface/BYOC thesis visually.

The story to tell

Piper is the PM colleague who actually knows your projects. Not a generic PM tool — a personalized assistant that learns how you work (meet-piper) and answers from your actual context (consult-piper enrichment). Show the before (floors, asks "what's on your plate?") and the after (knows your issues, names the real blocker).

Differentiator to highlight

Anthropic already has a generic PM plugin. Piper's advantage: personalization + "knows your context" + the meet-piper setup flow. The demo should make that tangible, not just stated.

Next steps for this track

PM to decide: Desktop only, or Desktop + Code? That shapes the script. Then: record with Loom, clip to 3-5 min, embed on pipermorgan.ai. No blocker — this can happen any time alpha is working.

Hosting Research Summary

Current hosting: DigitalOcean droplet · Caddy TLS + shared basic-auth · v0.8.7 · No new infra needed to prove marketplace mechanics.

Distribution research findings (R1, 2026-06-12):

  • Community catalog path (platform.claude.com/plugins/submit) is low-friction and real — automated review, SHA-pinned in 287-plugin catalog.
  • Official catalog has no submission process — Anthropic decides at discretion. Anthropic already has a PM plugin.
  • ChatGPT App Directory requires MCP server (which we're building) + OAuth 2.1 + UI widgets + manual review. ~60–70% reuse. Phase 3.
  • Smithery listing: separate low-effort win for Claude Desktop discoverability.
  • MCP Apps standard (Jan 2026) is the convergence mechanism — Claude + ChatGPT + Goose + VS Code. Building to this standard now has multi-platform payoff.

Auth research findings (R2, 2026-06-12): Option A (env var + meet-piper) is the right alpha path. OAuth is right for open/self-serve — Phase 3. The intent endpoint at /api/v1/intent accepts unauthenticated calls locally; Bearer token validation needed at Caddy layer for hosted access control.
