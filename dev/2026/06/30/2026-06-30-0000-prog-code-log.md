## sync→async DECISION (the real work)

4 store-touching methods) async. Blast radius was tractable: EVERY Slack-handler caller of
the converted methods was already inside an `async def` (FastAPI routes + webhook_router
async helpers), so threading `await` through was clean — no sync caller that couldn't be
made async, nothing to STOP-escalate. Calendar/GitHub OAuth handlers are separate classes
and untouched.

## Redis TTL replaces cleanup
setex(key, ttl_seconds, json) sets TTL from the 15-min expiry window, so expired nonces
auto-evict — the manual cleanup_expired_states sweep is deleted. get_oauth_status counts
live flows via SCAN over the prefix (every present key is live). A defensive expires_at
check remains in _verify_oauth_state (authoritative window) as belt-and-suspenders.
