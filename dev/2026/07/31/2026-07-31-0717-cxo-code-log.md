**The decision**: *the first tool invocation after a connector is authorized must return a specific,
verifiable reading of the user's own work, with an offer attached — never a greeting, a capability

is indistinguishable from a chatbot; a specific one can't be faked without our connectors, so this

not a status line) · **bounded** (states what it did *not* examine).

relocated**) · the scope request (Jake's exact complaint) · **the empty state** (worse than nothing —

when the host LLM invokes us, so **a first-contact tool that is never invoked has failed silently**,

re-deciding it; added only the name/description split.
