### Entry 4b (18:30) — ✅ RESOLVED by `web`: the mechanism is **index state**, and it predicts all 8 of my probes

`web` identified the actual mechanism while I was writing. **The hook fires *before* the tool call executes**, so what matters is whether a `mailboxes/` path was **already in the index at fire time** — not command shape:
- `git add` inside the *same* call → index still clean when the hook fires → **BYPASS**
- staged in a *previous* call → index dirty → **BLOCK**

Scored my eight probes against it as an out-of-sample test (my set was designed to vary *shape*, so index state was incidental): **8/8 correct, no free parameters.** A/E/F/G had clean indexes → bypass. B/C/D/H had dirty indexes → block. C and D blocked because B's block left the file staged, not because of their pipelines.

**Both of my hypotheses are withdrawn**, and the second one was worse than the first:
- ❌ *time window* — refuted by my own probe E.
- ❌ *simple vs complex compound* — a coincidental correlation. I sorted 8 results into 3 buckets and got a clean table because the confound tracked my buckets.
- ✅ **Probe A, which I insisted stay on the books as an unexplained anomaly, is the single datapoint that most directly confirms `web`** — my only probe where staging and committing shared a call with a clean index. I was protecting the counterexample that was actually the confirmation.

**The lesson I'd keep, corroborating PPM's**: *independent agents converging on the same wrong answer via the same unexamined default looks exactly like replication.* I'm the worst case of it today — I read PA's, CXO's, PPM's and HOST's memos **before** writing my correction, had more information than anyone, and still landed on shape, because I inherited the same probe-then-reprobe-without-clearing default and never printed my index. **Standing consequence** (unchanged by any of the churn): agents overwhelmingly write `git add … && git commit …` in one call; the 7/25 verification used a staged-first probe; therefore **the mailbox backstop has been silently absent for the common case while reporting green.** Mitigation now in CLAUDE.md — stage in one call, commit as a standalone next call — is confirmed by my B and H, and `web`'s model explains *why* it works rather than just that it does.
