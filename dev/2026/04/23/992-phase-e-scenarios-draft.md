### Branch-or-Anchor Discipline

Per CXO's Apr 26 ruling (paralleling PDR-004's no-paraphrase rule for canonical refs):

> *"When adapting a canonical rubric for local use, either anchor (cite + use canonical as-is) or branch (rename and version explicitly). Don't silently extend."*

Future activation gates, sub-epic gates, or scoring instruments should **either**:
1. Cite CT v2 by version and use it unchanged, **or**
2. Explicitly branch with a new name (e.g., "Phase E Scoring Rubric v1, derived from CT v2.0 with Clarity replacing Context")

This draft's failure mode — silently extending CT with the same letter for a different concept — is what the Branch-or-Anchor rule prevents.
