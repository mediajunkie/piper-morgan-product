## Decisions

- **Option (a): vendor DOMPurify 3.2.7 locally** at web/static/vendor/purify-3.2.7.min.js.
  Rationale: no CSP conflict, kills CDN dependency class entirely, jsdelivr reachable for a
  one-time fetch, file is 22KB. Escape-then-selective-allow (option b) rejected: markdown
  output legitimately needs a broad tag set (links with target/rel from #1123, lists, code,
  tables) — an allowlist re-implementation of DOMPurify is strictly worse.
- **Vendor marked at the exact version the CDN serves today (15.0.12)** at
  web/static/vendor/marked-15.0.12.min.js — byte-identical to current CDN payload
  (diff verified), so zero behavior change from pinning. Version in filename = pin visible.
- **Sanitize at renderBotMessage return (all non-thinking paths) in BOTH renderer copies +
  the chat.js raw fallback.** `ADD_ATTR: ['target']` to preserve #1123 new-tab links
  (DOMPurify strips target by default). Fail CLOSED when DOMPurify is missing: escape to
  plain text rather than pass raw HTML.
- **todo_handlers.py:288: NO source escaping** — see flow verification below; render
  chokepoint covers it; escaping at source would double-escape into visible artifacts.
