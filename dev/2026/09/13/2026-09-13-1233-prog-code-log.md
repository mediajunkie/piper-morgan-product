## Phase 2 — fixes (all four uncounted/false sites)

(the 6 are green controls, incl. the stale-claim control above); **27/27** post-fix.

- `TodoRepository.get_todos_by_owner_with_total` — `COUNT(*) OVER ()` rides the same
  LIMIT-ed query (#1645 idiom, no extra round trip). `get_todos_by_owner` delegates, so
  its list contract is unchanged for the callers that state no denominator.

  silent form — gains "(Showing the first N of M…)" only when truncated.

  `_gather_insight_pull_context.total_count` is now row-derived. `is_empty` deliberately
  left keyed on renderable rows — see the inline note; changing it trades one wrong
  render for another and needs the #1425 three-state treatment.
- `user_project_count` / `user_priority_count` companions + the floor renders the
  #1530 "that is the first N of M" clause over both.
