  a `from_domain()` would have to invent `chromadb_base_id` (NOT NULL, unique natural key
  only the ingester knows) and would drop `owner_id` + `is_global_pm_domain` — the two
  ADR-071 D1/D2 security fields. That is the "lie with a type signature," and a
  security-semantics-dropping one.
