## Fixes

1. **`services/mcp/protocol/protocol_client.py`** — `_pending_requests` keyed `Dict[str, …]`
   while `MCPMessage.id` is `str | int` (JSON-RPC 2.0 permits both). Widened the key type and
   annotated the `Future`. Clears arg_type −2, index −1, var_annotated −1.
2. **`services/mcp/consumer/github_adapter.py`** — added `_call_github_api_list()` for
   collection endpoints (9 call sites). `_call_github_api` is annotated
   `Optional[Dict[str, Any]]`, so iterating its result typed each element as `str` (dict
   iteration yields keys). **These were true positives**: a non-array payload would raise
   `AttributeError` at runtime. The wrapper delegates to `_call_github_api` (so every existing
   test mock seam is preserved) and returns `None` on a non-array — the signal all 9 callers
   already handle. Clears attr_defined −62 (211 → 149).
3. **Ceilings** lowered to measured values: attr_defined 190→149, index 45→44,
   var_annotated 70→69, misc 98→97 (misc had been 1 under since 08-31, unlowered for 10 days).
4. **Workflow** — added a `python -VV` + `pip freeze` echo step so the env hypothesis is
   falsifiable from the log rather than inferred from pip's "Downloading …" lines.
5. **Gotchas doc** — corrected the platform-skew entry that caused the misdiagnosis.
