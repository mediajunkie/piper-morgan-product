## What was built

`services/mcp/consumer/github_adapter.py` (`GitHubMCPSpatialAdapter`):
- `parse_github_url(self, url: str) -> Optional[Tuple[str, str, int]]` — pure, sync, no I/O.
  Regex `_ISSUE_OR_PR_URL_RE` matches `.../owner/repo/issues/{n}` and `.../owner/repo/pull/{n}`,
  optional trailing slash, http or https. Bare repo URLs (with/without trailing slash or `.git`),
  non-GitHub hosts, and malformed/non-numeric input return `None`.
- `get_issue_by_url(self, url: str) -> Dict[str, Any]` — composes `parse_github_url` +
  the existing `get_github_issue_direct` (same normalized issue shape: flat labels/assignees,
  `uri`, body under both `body`/`description` — #1736/#1760). Non-Optional return per the
  Protocol, so raises `ValueError` on an unparseable URL and `RuntimeError` on a failed fetch
  (same "no response" pattern `create_issue` uses) — never a fabricated issue.
- Added `import re` and `Tuple` to the typing import; added the module-level `_ISSUE_OR_PR_URL_RE`
  constant near the file's other module constants.
