## #1790 — LifecycleManager.transition() never records lifecycle_history

**Root cause**: `LifecycleManager.transition()` (`services/mux/lifecycle.py:394-398`) only checked
`hasattr(obj, "add_history")` and `hasattr(obj, "_history")`. The real domain dataclasses
(`Feature`, `WorkItem`, `Artifact` — `services/domain/models.py:257,329,885`) declare a plain
field `lifecycle_history: List[LifecycleTransition]` (matching the `HasLifecycle` protocol's own
contract at `services/mux/lifecycle.py:328`), which neither branch matched — transitions were
silently dropped for every real domain object.

**Fix** (`services/mux/lifecycle.py:394-400`):
```python
        # Record history
        if hasattr(obj, "add_history"):
            obj.add_history(transition)
        elif hasattr(obj, "lifecycle_history"):
            obj.lifecycle_history.append(transition)
        elif hasattr(obj, "_history"):
            obj._history.append(transition)
```
Added a middle branch that appends directly to `lifecycle_history` when present — this is the
attribute the protocol itself names, so protocol and manager now agree. `add_history` stays first
(explicit override), `_history` stays last as the original private-attribute fallback (no object
in the tree relies on it exclusively, but AC asked to preserve the path).
