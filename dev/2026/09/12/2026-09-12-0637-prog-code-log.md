## Fix shape chosen

Default OFF with explicit opt-in (`PIPER_DEMO_PLUGIN=1|true|yes`), because the sweep shows
legitimate dev/template uses (docs walkthroughs) but zero runtime dependents. An explicit
`plugins.enabled` listing in `config/PIPER.user.md` is still honored (operator choice).
Chose env-opt-in over dev_gate `PIPER_ENVIRONMENT` gating: dev_gate defaults to "development",
so a default (env-unset) deployment would still mount — absent-by-default is the stronger,
requested property.
