## Fix

One `now_user = now_in_zone(await user_timezone_name(user_id))` computed at the
top of `_handle_guidance_query`, right after the setup-request early return:
- `current_hour = now_user.hour` (drives the day-part bucket everywhere it did before)
- `timezone_short = zone_label(now_user)` (drives the face)
- Deleted the later `piper_config_loader.load_standup_config()["timing"]["timezone"]`
  read entirely — nothing else in this function used the `timezone`/`standup_config`
  locals.
- `time_context` changed from the bare `f"{current_hour}:00 {timezone_short}"` to
  `f"{now_user.strftime('%I:%M %p').lstrip('0')} {timezone_short}"` — a proper
  12-hour labeled face, matching the #1576-pattern renders elsewhere in this file
  (`_handle_temporal_query` L259-261, `_handle_agenda_query` L2769-2770).

file* — its only call site was the deleted block — but it is NOT deleted:

directly. Left in place with a comment stating exactly this.
