## Investigation

- `generated_at` originates in `_summary_to_legacy_dict` (line 43, pre-fix): `datetime.now(timezone.utc).isoformat()` — always a raw aware-ISO string.
- Site 1 (Slack fallback text, `_text_version` line ~461): called via `_format_for_slack` ← `_post_to_slack(self, user_id, standup)`. `user_id` **is** in scope at the immediate call site (`_post_to_slack`'s own parameter) — it just wasn't threaded down into `_format_for_slack`/`_text_version`.
- Site 2 (GitHub issue body, `_format_github_issue_body` line ~499): called via `_process_github_items(self, user_id, standup)`. Same shape — `user_id` in scope at the call site, not threaded into the formatting helper.
- Neither site reads a raw `context.get("user_id")`-style degradation, so `scripts/principal_threading_lint.py` was never implicated — this was pure internal threading (add `tz_name` param, compute once per outer async method via `await user_timezone_name(user_id)`, pass down).
- `format_iso_as_user_time` (datetime_utils.py) returns a **time-only** face (via `format_user_time`); the task explicitly wants the **date** visible too (`format_user_datetime` → `'2026-09-23 9:41 AM PDT'`). No existing helper parses ISO + returns date+time, so added a small module-level `_labeled_generated_at(generated_at, tz_name)` in the skill file that parses the ISO (same `Z`→`+00:00` handling as `format_iso_as_user_time`) and calls `format_user_datetime`; returns `None` on missing/unparseable input (never the raw string) so each call site chooses its own honest fallback.

### Before/after — Site 1 (`_text_version`)
```python
# BEFORE
def _text_version(self, standup: Dict[str, Any]) -> str:
    """Get plain text version for Slack text field"""
    return f"Daily Standup - {standup.get('generated_at', 'Today')}"

# AFTER
def _text_version(self, standup: Dict[str, Any], tz_name: str) -> str:
    """Get plain text version for Slack text field. ..."""
    face = _labeled_generated_at(standup.get("generated_at"), tz_name)
    return f"Daily Standup - {face}" if face else "Daily Standup"
```

### Before/after — Site 2 (`_format_github_issue_body`)

```python
# BEFORE
def _format_github_issue_body(self, item: Dict[str, Any], standup: Dict[str, Any]) -> str:
    return f"""From daily standup
**Item**: {item.get('title')}

**Date**: {standup.get('generated_at')}

...
"""

# AFTER
def _format_github_issue_body(self, item, standup, tz_name: str) -> str:
    date_face = _labeled_generated_at(standup.get("generated_at"), tz_name) or "unknown"
    return f"""From daily standup
**Item**: {item.get('title')}
**Category**: {item.get('category')}
**Date**: {date_face}
**User**: {standup.get('user_id')}
...
"""
```
