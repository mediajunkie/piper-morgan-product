   same `(workflow_type, session_id, user_id=None, ...)` convention as the

2. **`_process_intent_internal`** added to `KEYED_CALL_NAMES` — `IntentService`'s
   real internal entry point, same `(message, session_id, user_id=None,
   ctx=None)` signature as the public wrapper. Evidenced in file #8.
3. **Tokenize-based `_scan_text()`** — replaces what was, mid-batch, a hand-rolled
   whole-line-comment-only stripper (superseded before landing) with a
   stdlib-`tokenize` pass that blanks every `COMMENT` and `STRING` token
   (docstrings, trailing inline comments, and any other string literal —
   e.g. a `patch("...process_intent")` target path) to same-length whitespace,
   preserving character positions so `_call_text()`'s original-text offsets
   stay valid. Falls back to the untouched original text on a tokenize
   failure. Evidenced in files #5 (docstring), #9 (comment), and
   `test_standup_routing_585.py` (docstring, discovered mid-batch).
   **Bug caught and fixed during authoring**: the fallback except-clause
   referenced `tokenize.TokenizeError`, which doesn't exist (correct name is
   `tokenize.TokenError`) — caught by the new
   `test_falls_back_to_original_on_tokenize_failure` test, which would have
   silently masked every genuinely-broken fixture file with an
   `AttributeError` instead of the intended graceful fallback. Verified no
   real file in `tests/**/*.py` actually hits the fallback path (swept the
   whole tree with the fixed except-clause: 0 files fell back).
4. **JWT-bearer-route fallback** (`_ACCESS_TOKEN_CALL`/`_BEARER_TOKEN_USAGE`) —
   for a file already matched keyed with `real == 0`, additionally checks for
   a `generate_access_token(user_id=<non-None>)` call AND the literal
   `Bearer {token}` usage pattern; if both present, treats the file as
   carrying a real principal threaded end-to-end through the production
   route rather than a literal kwarg in the test file. Scoped to
   already-keyed files only — never inflates `KEYED` on its own (pinned by
   `test_generate_access_token_alone_does_not_inflate_keyed`). Evidenced
   identically in files #10–14 (5 web/ files sharing one harness idiom).
5. Docstring rewritten to keep "known blind spots" honest and record the
   full batch-5 accounting (widened denominator, discovered-work triage,
   before/after numbers).
