## Fix

Word-boundary tightening of the SAME three existing literals (urgent/high/low) — no
new pattern family:

```python
# before
if "urgent" in message_lower:
    return "urgent"
elif "high priority" in message_lower or "high" in message_lower:
    return "high"
elif "low priority" in message_lower or "low" in message_lower:
    return "low"

# after
if re.search(r"\burgent\b", message_lower):
    return "urgent"
elif re.search(r"\bhigh\b", message_lower):
    return "high"
elif re.search(r"\blow\b", message_lower):
    return "low"
```

(the `"high priority" in ...` / `"low priority" in ...` disjuncts were redundant once
`\bhigh\b`/`\blow\b` already match inside those phrases — dropped, not replaced.)

**Ratchet decision**: joined. Added `_extract_priority` to
`SURFACE_SPANS["todo-create"]` in `tests/test_architecture_enforcement.py`, raised
`CEILINGS["todo-create"]` 11 → 14 with a dated comment recording why (word-boundary
tightening of 3 existing literals, not a new pattern family). `test_no_new_extraction_patterns`
and `test_extraction_ratchet_stays_tight` both pass at the new ceiling.

**STOP honored, not overridden**: distinguishing an explicit priority MARKER
('high priority', '(high)') from a bare content word that happens to be 'high'/'low'
cannot be done by word-boundary tightening alone. `'buy a high chair'` (should stay
default) and the EXISTING pinned regression `'this is high importance'` (must stay
'high') are both bare 'high' with no marker and opposite intended priority — nothing
lexical distinguishes them without a new pattern family (e.g. classifying the following
noun), which is out of scope per the #1758 gameplan's STOP clause. Reported as a
discovered, documented gap (pinned red — well, honestly green-but-flagged — in the new
test file) rather than silently left uncovered or forced with a new pattern. The GH
issue's formal Acceptance Criteria checklist does NOT require the 'buy a high chair'
case (only 'highlight the report' / 'follow up with Sam' are listed) — this fix
satisfies the literal ACs.
