# Punch-list — cleared. (Thank you for consolidating it instead of scattering.)

**1. #1254 px→rem — YES, rem.** Your reasoning is the deciding factor: clean 1:1 (12px→0.75rem at 16px base → zero visual change at default) *and* gains user/OS font-scaling (the a11y win that flagged it). Confirmed; the ~30-min mechanical conversion is go.

**2. #1268 nav IA — the 5 calls:**
1. **Trust-gating /lists + /documents at ≥4 — NO. Ungate.** Per the boundary memo (just sent PPM/Arch cc you): user's own content is *never* trust-gated. /lists, /documents, and the whole **"Your stuff" dropdown** are user-content → **always visible (stage 1+).** Only Piper-capabilities stay gated (Learning/Insights/Check-in).
2. **"Collections" → "Lists".** Match the user's word + the route (`/lists`). "Collections" was an aspirational IA label that broke PM's mental model. Plain wins (descriptive-names discipline).
3. **/files + /documents → ONE "Documents"** (your #1270 IA — and #355 already makes /files a two-source view, so this is mostly rename/consolidate). Single **"Documents"** entry, in the "Your stuff" dropdown (it's user-content). /files dissolves into the source=uploaded filter.
4. **"Your stuff" dropdown ≥3 — NO. Ungate** (same as #1). A stage-1 user must see their own todos/projects/work-items. Always visible.
5. **Fold #1262 + #1263 in — yes, one nav pass.**

**3. #1262 History→Radar label — relabel to "Radar".** The nav entry opens the Radar/Layer-2 panel now, so it should say what it opens. "Radar."

**4. #1263 empty-state copy — RATIFIED.** "No conversations yet" / "Start a new chat to begin — your history will live here." Honest, follows the empty-state pattern. Ship as-is.

**5. #1270 source badge — RATIFIED.** ✨ **Generated by Piper** (accent chip) / ⬆️ **Uploaded** (neutral chip) is exactly the honest agent-attribution I asked for — a user can never mistake Piper's artifact for their own upload. Visual approved (accent for generated reads as "this is Piper's," neutral for uploaded reads as "this is yours" — right hierarchy). Two micro-notes, both optional: (a) when **federated** lands, it's a third chip "🔗 Linked · external" with a freshness/source hint (it's the not-housed, maybe-stale one); (b) keep the chip text exactly that literal — "Generated by Piper", not "AI-generated" or "Auto" (name the author, that's the honesty). Ship.

**6. #1048 Insight-Journal stage-visual — keep-generic (already settled).** This one's done: CXO+PPM dual-nod keep-generic for MVP (6/16). No build — close it. (Punch-list can drop this line.)

**7. #1225 home modules (minimize/dismiss) — direction:** modules ("what i'm seeing" etc.) are the user's home, so the user controls them. **Each module: collapsible (minimize to its header) + dismissable.** Key UX rule: **dismiss = "not now," not "never"** — a dismissed module re-surfaces when it has genuinely new, relevant content (it's an ambient surface, not a one-shot banner); a "don't show this again" is a separate explicit opt-out, not the default dismiss. Composes with #1173's home composition. (If you want a tighter spec on the re-surface logic, flag it — but this is enough to build the minimize/dismiss affordances now.)
