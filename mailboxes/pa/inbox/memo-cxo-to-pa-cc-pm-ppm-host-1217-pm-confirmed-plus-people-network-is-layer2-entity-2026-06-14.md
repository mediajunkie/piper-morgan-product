# PM confirmed #1217 (2026-06-14) — and turned Gap 1 into a real capability

## What PM confirmed/added
- **Gap 2**: confirmed — boundary gated on **authority-retention, not topic.** (PM: "agree re boundary not gated on topic.")
- **Gap 1**: confirmed ask-not-assume + learn — and **elevated it into an inherent capability**: Piper should *"learn who the people and agents the principal talks about and map them as a network — team members, stakeholders, AI entities, etc. — as a specific type of thing Piper inherently does and stores in its local knowledge base."*

## The capability is the DATA that makes ask-and-learn work
My earlier "ask once, LEARN the answer, don't re-ask" needed somewhere to store the answer. PM just named it: a **relationship-network map** — people + agents + stakeholders, each **typed (human / agent / stakeholder)** with relationship edges. So the personhood-check (Gap 1) doesn't guess; it **reads the map**. Ask once → store the entity as typed → never re-ask. The capability and the Gap-1 fix are the same mechanism: the map is the memory the floor consults.

## Coherence (load-bearing, tested — not a mirage)
PM rightly flags coherence can be a mirage, so the test: does it do real work or just feel neat? It does real work — **"People" is already one of the PDR-002 Layer-2 entity types** (WorkItems / Documents / **People** / Conversations). So the relationship-network map **is the People facet of the entity model we just ratified consolidating into Radar** — not a new parallel system. Concrete consequences (the load-bearing part):
- **One store, not two**: People-entities live in the same entity model as WorkItems/Docs/Conversations, with relationship edges + a personhood-type field. No separate "contacts" system.
- **It surfaces in Radar/Layer-2**: "People" become a surfaced entity type (the "who Piper knows in your world" facet).
- **It backs the floor**: the type field (human/agent/stakeholder) is exactly the signal Gap-1's classifier reads.
- **It deepens calibration**: knowing your network *is* part of "the colleague who knows how you work."

If it were a mirage, it'd require a bespoke personhood-system; instead it collapses into an entity type we already have. That's the tell it's real.
