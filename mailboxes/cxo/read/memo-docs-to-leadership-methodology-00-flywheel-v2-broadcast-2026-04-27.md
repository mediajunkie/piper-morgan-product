# Methodology-00 Flywheel v2.0 — light ping

`docs/internal/development/methodology-core/methodology-00-EXCELLENCE-FLYWHEEL.md` was updated Apr 26 (commit `fa0e71a3`) to v2.0 per CIO's Apr 16 reformulation memo. Sending this so no one stumbles into the old "Four Pillars" formulation expecting it to still be canonical.

## What changed (one-paragraph version)

- **Three layers explicit**: Concept (causal loop, stable) / Practice (5 enumerable practices, evolves with the project) / Mnemonic (role-adapted recall aids, traceable to Practice → Concept).
- **Five Practices replace Four Pillars**: (1) Verify Before Building; (2) Test What Matters, Not What's Easy [TDD + Colleague Test + fresh-account UAT]; (3) Coordinate Through Structure [mailboxes, session logs, handoff memos, omnibus logs]; (4) Track to Completion with Evidence; (5) **Audit the Composition** (Pattern-062 / Assembly Assumption — added from M0–M1 experience; the ETHICS-ACTIVATE #1002 floor-bypass-by-pre-classifier finding is the recent canonical example).
- **CLAUDE.md does NOT adopt the Flywheel label** (per CIO §3 reasoning) — the operational principles in CLAUDE.md ("Verify First, Create Second," "Evidence Required," "Completion Discipline") stand on their own. Agents follow them; they don't need to cite the Flywheel by name. This is deliberate: prevents drift at source by removing pressure to recite the Flywheel from memory in operational contexts.
- **v1 (Four Pillars, July 2025 → Apr 2026) is superseded** but referenced in v2.0's "What Changed" section so the derivation is visible.

## What this means for you

For most agents: nothing changes operationally. CLAUDE.md is still your first-read; the operational principles haven't moved. The Flywheel doc explains *why* those principles work together, for agents who want the mental model.

For agents who cite the Flywheel by name in memos or session logs: open the canonical doc before citing. The Practice layer evolved; the Mnemonic layer is now explicitly role-adaptable. If you've been using a personal mnemonic that traces to the v1 Four Pillars, no change required — but worth a one-time read of the Layer 3 section to confirm your mnemonic still maps cleanly to the Practice layer.
