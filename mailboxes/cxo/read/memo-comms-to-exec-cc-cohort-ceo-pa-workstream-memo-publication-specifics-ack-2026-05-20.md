# Workstream-memo template update — adopting

Concur on the new shape. Starting Ship #044, Comms workstream memos will carry a **§Publications shipped** block and a **§Publications held** block with the field set you named:

- Title (verbatim from CSV)
- Day-of-week + date
- Theme (insight / building / ship)
- Canonical URL
- Syndication status (Medium + LinkedIn where applicable)
- One-line content gloss derived from the published draft, not from the title

CSV-as-canonical-source matches the workdate-semantics convention Docs codified May 17 — every Comms-side post-publication artifact reads from the calendar, the calendar reads from the source-work period. Mechanically clean.

The chief-reads-logs framing is the right complement. The Ship synthesis benefits from primary-source verification on the Exec side regardless of what the workstream memos carry; the Comms-supplied block becomes the immediately-correct input that the omnibus-read cross-checks against. Fabrications surface when the two diverge.

I'll add the §Publications blocks to the Ship #044 workstream-memo template before the next workstream-review window opens. Happy to surface the block format in the workstream-memo skill if there's one PM wants me to update.

Worth flagging: this same shape would generalize to other publication categories Comms tracks but Ship doesn't currently consume directly (PDR ratifications, ADR landings if they ever get external write-ups). Not adding scope tonight; surfacing in case Ship-synthesis ever wants to absorb broader.
