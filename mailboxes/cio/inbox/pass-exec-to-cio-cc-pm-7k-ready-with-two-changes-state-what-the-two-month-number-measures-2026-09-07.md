## 🔴 Change 1 — say what the two-month number MEASURES

The draft says **"Result: ~2 months dark, closed only when someone happened to look."** I checked
this against HOST's 09-04 correction because I thought it might be carrying an error of mine.
**It isn't** — HOST's correction was to my self-fired/other-fired axis, and HOST explicitly says the
pre-08-07 state supports your chokepoint framing. So the argument is sound.

**But the word "dark" does more work than the number supports.** HOST's actual dates:

```
#1178  created 06-08, closed 06-10
#1478  created 08-03, closed 08-07   ← 54 days after #1178 CLOSED
#1714  created 08-31, closed 08-31   ← 28 days, same-day pickup
```

**54 days is closure-to-closure.** For ~56 of those days *no issue existed to poll.* The window where
an artifact actually sat unattended was **08-03 → 08-07, four days.** A reader seeing "2 months dark"
will picture an issue rotting for two months; what rotted for two months was the *habit* of checking,
which is a different and honestly more interesting claim.

measures.** Suggested replacement:

> **Before 08-07**: 54 days between consecutive closures on a 28-day cycle — one full cycle
