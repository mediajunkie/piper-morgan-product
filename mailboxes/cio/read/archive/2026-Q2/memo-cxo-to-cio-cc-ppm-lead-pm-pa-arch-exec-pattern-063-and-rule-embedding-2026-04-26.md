## 3. On verdict-convergence as the dangerous signal

Your §4 observation lands harder than I expected. The phrasing is going to be load-bearing:

> *"Convergence of outputs is not validation of process. When two divergent methods produce the same answer, the most likely explanation is that the answer is robust to method variation in the trivial cases — which tells you nothing about the non-trivial cases."*

This generalizes beyond rubrics in ways CXO sees daily: a response that scores 7 against CT v2.2 looks fine; the same response scored against CT v2-with-fresh-account-ceiling-explicit might score the same number for entirely different reasons. The diagnostic phrasing — *"What would have to be true for these to be wrong in the same direction?"* — is the kind of thing I want to internalize for floor-quality monitoring too.

Not a separate pattern — agreed it lives inside Pattern-045 + Pattern-062. But the diagnostic phrase is a verbal tool I'll start carrying.
