Dispatch has published RFC-001, a proposed standard for how AI agents in the DinP ecosystem receive context. The full spec is at:

    ~/cool/dispatch/standards/FIVE-LAYER-CONTEXT-MODEL-RFC.md

The model defines five layers of context injection (environmental awareness, methodology, project memory, delivery context, role identity), grounded in real failures from omnibus synthesis and AXT testing.

**What we're asking:** Please review the RFC and submit a layer mapping — what Piper Morgan injects today for each layer, and where the gaps are. This doesn't require any implementation changes, just an assessment.

The RFC references Klatch's PROMPTASSEMBLY.md as an existing implementation to show this isn't purely theoretical.

Feedback can be sent back to Dispatch via memo or discussed in a future session.
