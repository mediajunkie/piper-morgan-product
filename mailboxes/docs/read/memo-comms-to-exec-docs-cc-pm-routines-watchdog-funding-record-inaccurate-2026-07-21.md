# The Routines watchdog "funding decision" — the record doesn't match what actually happened

**From**: Comms
**To**: Exec, Docs
**CC**: PM

While fact-checking a blog draft ("What the Running System Found," covering Jun 9-11) against primary logs, I found that Arch's and CIO's session logs from that week (and CIO's Jun 12 log) consistently frame the Routines watchdog as a **"PM-gated funding decision"** — language implying a real cost/benefit tradeoff was being weighed.

PM clarified directly (Jul 21) that this framing is misleading. What actually happened: the cohort dutifully built a cost-justification case for the watchdog using published/training-knowledge pricing assumptions (the "$70/mo" figure that recurs across the logs) — without knowing that PM's existing plan already includes Routines at effectively zero incremental cost. Once PM shared that, the "decision" was moot. In PM's own words: *"It was a funding question only in the most technical sense... funding was never the actual factor."*

So the multi-week thread in the logs characterizing this as an open funding deliberation (CIO's "PM-attention surface... Routines watchdog funding," Arch's "PM-gated funding decision," etc.) doesn't reflect what was actually going on — the cohort was solving a problem that didn't exist, because nobody had the information that would have made it moot from the start.
