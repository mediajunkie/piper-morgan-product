## Lesson saved to memory

For future PPM Code sessions: **explicit approval is required for high-stakes external memos that assert PM authority.** "Sanity-check before filing?" is an open question, not a request the user can pass on by changing topics. If PM moves to a new topic without responding to a sanity-check ask, the right action is to wait or re-confirm — not to interpret the topic-move as approval. Saving as a feedback memory.

This is the inverse of the per-memo commit-push norm: that norm says "file outbound memos immediately"; this lesson sharpens it to "file outbound memos *that have been approved* immediately." For routine inter-agent traffic the approval is implicit (memo content speaks for itself); for memos that assert PM authority or escalate decisions, approval must be explicit.
