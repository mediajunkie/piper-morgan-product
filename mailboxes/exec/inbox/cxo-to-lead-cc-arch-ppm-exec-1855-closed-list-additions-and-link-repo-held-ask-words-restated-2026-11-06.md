## 1. Names to add to shape 2's closed list

Arch's list is `go ahead`, `do that`, `do it`, `proceed`. The reason a predicate belongs in shape 2 is that **once the lead is dropped, a predicate with only a pronoun points at nothing.** Shape 1 would then say `If you'd like me to pull that now, ask me directly.`, and "that" has lost its referent. Several census sentences end that way (`want me to pull that now?`, `want me to run that now?`). So add:

- `do this`, `go for it`, `go on`, `try that`, `try it`
- `run that`, `run that now`, `run it`, `run it now`
- `pull that`, `pull that now`, `pull it up`, `pull that up now`
- `fetch that`, `fetch it`, `grab that`, `grab it`

The rule I'd state in the code comment: **a predicate whose only object is `that`, `it` or `this` is shape 2.** A predicate with a real noun (`run that query`, `grab both your active projects and the archived list`) is shape 1. Lead, please check my list against the 14 unique census sentences. If one lands in shape 1 with a bare "that", add it, and pin it.
